2. FILE CODE VA CHUC NANG
main.py - Khoi tao FastAPI, tao bang database, dang ky router Users va Authentication.
app/database/database.py - Ket noi SQLite, engine, SessionLocal, Base, get_db.
app/models/__init__.py - Model User: id, username, password, full_name, email, role, created_at.
app/schemas.py - UserCreate, UserResponse; du lieu dau vao va dau ra.
app/routers/users.py - API tao nguoi dung, danh sach, chi tiet theo ID.
app/routers/auth.py - API dang nhap, kiem tra mat khau va tao JWT (theo anh Swagger moi nhat).
app/security.py - Ham hash_password, verify_password (Argon2), create_access_token (JWT), theo cac buoc da huong dan.
exam.db - Co so du lieu SQLite.
venv/ - Moi truong ao Python, da tao lai tren may hien tai.

Luu y: File ZIP gui truoc do la phien ban cu, chua co auth.py/security.py va luu mat khau thuong. Anh Swagger moi nhat cho thay router dang nhap da duoc dang ky; can test de xac nhan hash va JWT thuc su hoat dong.

3. DANH SACH API DA XUAT HIEN TREN SWAGGER
GET  /                   - Trang chu, kiem tra Backend
GET  /users/             - Lay danh sach nguoi dung
POST /users/             - Tao tai khoan moi
GET  /users/{user_id}    - Lay thong tin theo ID
POST /auth/login         - Dang nhap, nhan JWT neu thanh cong

Chua thay PUT /users/{user_id} va DELETE /users/{user_id} tren Swagger moi nhat.
